# coinflip-cli

Build a tiny CLI tool called "coinflip" that flips a virtual coin and prints heads or tails, with a --count N flag to flip N times and print a summary of heads/tails counts.

## Goal

Ship a minimal, working CLI (`coinflip`) that:
- With no flags, flips a single virtual coin and prints "heads" or "tails".
- With `--count N`, flips N times and prints a summary tally of heads vs tails counts.
- Is simple, well-tested at a basic level, and installable/runnable locally as an MVP.
